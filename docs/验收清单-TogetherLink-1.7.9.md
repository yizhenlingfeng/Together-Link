## 0. 启动与握手

- [ ] 单人/集成服务器启动到主菜单，无 `Mixin apply` / `InjectionException`。
- [ ] 连接原版或只装 BBS、未装 Together 的服务器：BBS 编辑界面仍可操作，不出现“整页只读”。
- [ ] 连接 Together 服务器：进服后延迟 1–2 秒内进入正常权限状态，`c_bbsop_sync` 等级正确。
- [ ] 旧版 Together 服务器（无 hello）：仍能识别并进入同步，而不是全只读。

## 1. 权限等级与锁

准备两个客户端：A（等级 2 管理员/服主）、B（等级 0 或受限等级 1）。

- [ ] A 锁定模型/影片/模型方块（白名单或黑名单）。
- [ ] B 看到模型灰色遮罩 + 闭合锁；影片列表闭合锁；模型方块 F3 锁图标。
- [ ] A 作为锁创建者：模型格右下角闭合小锁，影片列表打开的锁头；B 看不到管理员标记。
- [ ] B 右键锁定模型方块：不打开面板；左键破坏：方块与模型保持，不出现“方块还在、模型消失”。
- [ ] A 的锁菜单同时显示白名单/黑名单两个入口，切换模式不丢另一份名单。
- [ ] 受限等级 1 的域白名单生效：被禁止的 `model_editor`/`textures`/`audio`/`particles` 上传被服务端拒绝。

## 2. 资产同步 / mtime CAS

- [ ] A 上传新模型，B 在 manifest 后自动下载，sha1/大小正确。
- [ ] A、B 同时修改同一个资产并上传：
  - [ ] 先到者成功；
  - [ ] 后者收到 stale base 拒绝并重新拉 manifest，不静默覆盖先到者。
- [ ] 客户端写队列：连续上传多个文件，分片顺序正确，无 0 字节/半文件。
- [ ] 服务端控制台无上传线程异常，服务器 tick 未因大文件上传卡死。
- [ ] 多分片上传中断后，临时 `.bbsup` 不再被下一次上传误用；下一次 manifest diff 能重试。

## 3. CDN（可选）

在客户端设置 CDN 地址（可留空 token）：

- [ ] 配置正确时，缺失资产优先从 CDN 拉取，SHA-1 与大小校验通过。
- [ ] CDN 404/超时/内容错误时自动回退服务器，客户端仍能完成同步。
- [ ] CDN 地址留空时行为与旧版一致。
- [ ] 上传始终走服务器，不因 CDN 配置被跳过。

## 4. Tombstone / 恢复

- [ ] A 请求删除模型，管理员审批删除。
- [ ] 删除后的模型在 manifest 中消失，离线客户端重传被服务端丢弃。
- [ ] 重启服务器后仍然不会复活。
- [ ] 控制台/OP 执行 `/bbstogether restore <模型>` 后，tombstone 清除，客户端可重新上传。
- [ ] 恢复命令不会凭空恢复已删除文件。

## 5. 文件夹与影片生命周期

- [ ] 重命名包含多部影片的文件夹：影片列表、锁、提交图、玩家当前选择跟着迁移。
- [ ] 删除文件夹：相关影片从列表消失，提交/分支数据清理，玩家不会停留在已删除影片。
- [ ] 非默认分支玩家保存：BBS 主影片文件不被分支内容覆盖；切回默认分支内容正确。
- [ ] 打开两个客户端同时编辑同一影片的不同分支，保存互不覆盖。

## 6. 合作录制

- [ ] A 邀请 B 进入合作录制；录制期间资产锁/影片写锁生效。
- [ ] 合作期间通过旧快照/撤销通道不能覆盖影片。
- [ ] 结束合作后，保存/提交/切分支恢复正常。

## 7. 行为日志

- [ ] 服务端观察到的上传/下载记录不带 `source` 字段。
- [ ] 客户端模型编辑器上报记录带 `source=client`。
- [ ] 等级 0 客户端不能上报；等级 1 每 250 ms 最多一条。
- [ ] 非 `SUB_EDIT_MODEL` 子类型、超长 target/item 被拒绝。

## 8. 回放 / 菜单 / 显示

- [ ] 回放列表新增/删除/复制/粘贴/改分类同步正常，无 `CancellationException`。
- [ ] BBS-Cubed 右键菜单的附加项仍显示；只读/锁定玩家只保留删除项。
- [ ] 录制回放/录制视频按钮只出现一层锁图标，权限变化即时生效。
- [ ] 玩家进入影片界面时隐藏模型渲染；只是选中影片时不隐藏。

## 已知剩余项

- CDN 仍为只读下载回退，不支持 CDN 上传/CDN manifest/token 刷新。
- `client-bbs-together-refmap.json` 仍是旧文件；生产 jar 的注解已 remap，启动冒烟通过。
- 提交图已做可见边裁剪，但全量 rebuild/布局仍有优化空间。
- 行为日志仍无服务端签名/审计链，只有来源标记、类型/长度校验和限流。

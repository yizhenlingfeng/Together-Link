# Together Link

Together Link（原名 BBS Together）是 [BBS FS](https://github.com)（Blockbench Studio for Minecraft）的多人协作模组，基于 Minecraft 1.20.1 Fabric。它让多名玩家在同一个 BBS 影片项目中实时协作编辑，同步光标、选中、关键帧、回放，并支持资产和影片数据的服务器端分发。

- **模组 ID**：`bbs_together`（历史沿用，未改动）
- **当前版本**：1.7.5
- **Minecraft**：1.20.1
- **前置**：BBS FS >= 2.6、Fabric API、Fabric Loader >= 0.15.6
- **Java**：17（编译目标）/ 21（运行 Gradle 9.2）
- **许可**：MIT

---

## 功能介绍

### 实时协作
- **玩家颜色标识**：每名玩家自动分配一个颜色，在 BBS 界面中以彩色高亮显示其选中内容与光标位置。
- **共享光标**：其他玩家的鼠标光标在当前编辑界面实时可见。
- **选中同步**：表单、关键帧、回放片段的选中状态会广播给所有在线玩家。
- **表单锁定**：一名玩家编辑某条回放的表单时，其他玩家看到锁定状态，避免冲突。
- **回放交换**：玩家之间可以交换回放片段的顺序。

### 影片与回放同步
- **影片选择同步**：谁在编辑哪个影片、停留在哪个影片屏幕，其他玩家可见。
- **影片数据实时同步**：一名玩家保存关键帧/轨道修改后，影片数据自动推送给所有在线玩家，无需手动重传。
- **影片列表/重命名/删除同步**：新增、重命名、删除影片时列表在所有客户端刷新。
- **回放合并**：支持多人录制的回放片段合并到同一时间线。

### 录制同步
- **一键录制开关**：服务器管理员可通过命令同时控制多名玩家开始/停止录制。
- **主录制协调**：指定一名"主录制"玩家，其时间线作为基准，其他玩家的录制片段在主录制结束后自动对齐合并。

### 合作录制
- **发起请求**：影片编辑页「录制回放」按钮右键 →「请求合作录制」，弹窗多选服务器在线玩家（头像 + 名字）后发出邀请。
- **置顶邀请弹窗**：被邀请玩家在右上角收到置顶请求（任何界面可见，包括不在 BBS 界面时），显示发起者、影片名、可同意剩余时间的倒计时条；快捷键「同意 / 取消」可在 BBS 设置的「影片控制器」分类中改键。
- **选回放房间**：同意后双方进入房间——左侧为影片全部回放（方框 + 小字名称），右侧为成员列表（灰色 = 未选择、绿色 = 已选择，发起者带 ★）；房间内实时显示各成员鼠标位置；点击回放认领（框上显示认领者头像并锁定），右键自己的认领取消。
- **协同录制**：全员认领后发起者点「开始录制」，服务器同时拉起所有成员的录制（各自录入自己认领的回放，可中途停止）；全员交卷后服务器合并进影片并广播。
- **服务器权威**：会话期间与合并后 30 秒内锁定该影片的客户端写入（全量/逐通道同步被拒），杜绝成员本地旧状态覆盖合并结果；一玩家同时只能在一个会话，一部影片同时只允许一个会话。
- **审计**：合并完成在行为列表记录一条合作录制条目（发起者、成员与各自认领的回放）。
- **邀请时限**：`bbs_together.config.coop.coop_invite_seconds`（默认 60 秒，范围 10–600）。

### 资产同步
- **资产清单（Manifest）**：玩家进入服务器时，服务器把 `config/bbs/assets/` 下所有资产（纹理、模型、音频、粒子等）的 SHA-1 与文件大小清单发给客户端。
- **自动下载**：客户端发现本地缺失或不一致的资产时，自动从服务器请求下载。
- **自动上传**：客户端本地新增或修改的资产自动上传到服务器，服务器落盘到 `config/bbs/assets/`，作为权威存储（last-write-wins）。
- **大小保护**：客户端可在 F6 面板设置单文件大小上限（默认 1024 MB，范围 16 MB–2 GB），超过上限的文件自动跳过不下载/上传。
- **超限模型标记**：总大小超过上限的模型文件夹仅下载 `config.json` 占位，在模型列表中标记为红色"模型过大"。
- **手动同步按钮**：F6 实用工具面板提供"下载全部模型"和"上传全部模型"按钮，点击后请求服务端重发清单，仅同步差异文件（不强制全量重传）。
- **上传节流**：文件逐个发送，间隔 200ms，避免 crusher 分片洪水导致断连。

### 关键帧默认样式
- 可在 BBS 设置中为新建关键帧指定默认颜色、形状、插值方式，统一协作时的关键帧风格。

### 服务器行为列表
- **审计日志面板**：底部导航栏新增面板，记录玩家在服务器上的编辑 / 下载 / 上传历史，存档持久化到 `<存档>/bbs/behaviors/`。
- **内容对比记录**：模型保存、影片保存、资产上传都会先与上次状态做内容对比，未实际改动不产生记录；上传自动聚合为模型，皮肤与压缩包不记录，并统计传输大小。
- **三栏布局**：左侧玩家列表（仅 OP 可见，非 OP 显示"没有权限"）、中间行为列表（类型图标 + 描述 + 时间，新的在底部）、右侧详情（时间 / 玩家 / 大小 / 剪辑等）。
- **点击跳转**：详情中的模型条目可跳转到 morph 面板并选中该模型；影片条目可跳转到影片面板并选中对应剪辑。
- **OP 管理**：右键玩家可设为 / 解除 OP（带确认与服务器日志），可移除该玩家的全部日志（二级确认）。
- **隐私保护**：非 OP 玩家可见行为内容但所有头像与名称完全匿名，由服务端剥离身份数据。
- **日志容量**：`bbs_together.config.behaviors.behavior_log_limit`（默认 1000，范围 100–50000），超出后自动淘汰最旧条目。

### 模型删除请求
- **请求服务器删除**：模型列表右键任意模型 →「请求服务器删除」，确认后在服务器行为列表生成一条待审批请求。
- **审批闭环**：管理端（原版 OP 或 BBS 2 级）在行为列表右键该请求即可「同意 / 拒绝」；同意后服务器删除该模型资产并广播所有客户端删除本地拷贝；拒绝后条目灰渐变标注红叉与「已拒绝」。等待审批的条目灰字标注，详情页显示审批状态与审批人。
- **防复活 tombstone**：模型从服务器删除后，30 分钟内自动同步客户端对该模型的重传会被服务器丢弃，避免被 sha1 差异对比"复活"。
- **仅本地删除**：右键 →「仅本地删除」只删本机拷贝；开启自动同步时确认菜单直接提供「关闭自动同步并删除 / 仍要仅删除 / 取消」，避免模型被重新同步回来。
- **只读可见**：0 级只读玩家的模型右键菜单只显示这两个删除项（请求需管理端审批，本地删除只动本机文件），其余编辑操作照旧全部锁定。

### 撤回撤销防误撤
- 远端同步数据落盘前先封存玩家进行中的撤销批次，保证撤销条目的"改后快照"只含玩家自己的修改。
- 撤销同步到服务器时按路径携带期望基线（`s_undo_sync`）做校验，他人已改过的内容会被拒绝并回推服务器现状（`c_undo_rejected`），杜绝"Ctrl+Z 一键回滚他人修改"。

### BBS 权限等级（bbsop）
- **三级权限**：0 级仅浏览（可浏览、可下载，不可编辑、不可上传）、1 级编辑者（默认可编辑全部内容）、2 级管理员（可编辑全部内容并管理他人权限）。玩家进服默认 0 级。
- **功能域**：伪装、影片、模型方块、粒子、模型编辑器、纹理、音频编辑器、资产上传八个域，服务端写包与客户端 UI 全部按域判定。
- **录制子权限**：影片域下的隐藏子域「录制」，控制回放录制（录制按钮、录制快捷键、`/bbstogether record` 远程触发）与影片预览的「录制视频/截图」按钮。它不占「修改可编辑行为」菜单的顶层项——鼠标悬停「影片」行时在右侧弹出「录制：允许/禁止」小按钮切换；服务端在录制数据包与动作录制两条通道复核。
- **1 级域白名单**：管理员可对 1 级玩家逐域"允许/禁止"；首次禁止即进入白名单模式（其余全开），空白名单 = 全部禁止。
- **管理入口**：服务器行为面板玩家列表——拖拽玩家到目标等级分组即可换级；右键「修改 BBS 等级」「修改可编辑行为」子菜单。仅 2 级玩家可管理（原版 OP 走 `/bbsop` 指令）；管理员不可拖动修改自身等级、不可解除自身 OP。
- **等级分组**：玩家列表按 2 → 1 → 0 三级分组显示，等级持久化到 `<存档>/bbs/bbsop.json`，玩家每次进服自动归入原分组；点选分组标题可按组过滤行为列表。
- **服务端权威**：上传、影片写入、模型方块、远端录制等所有写通道在服务端按域复核，改客户端也无法绕过；0 级玩家进入 BBS 各编辑页呈只读态（灰罩 + 锁图标 + 仅浏览）。
- **即时生效**：等级 / 域变更后服务端立即推送，目标玩家 UI 无需重进即切换锁定状态。

### 服务器命令
- `/bbstogether record <玩家>`：切换指定玩家的录制状态；若其中有人正在录制，则停止所有目标玩家的录制。
- `/bbsop <玩家> [0-2]`：查询或设置玩家的 BBS 权限等级（0 仅浏览 / 1 编辑者 / 2 管理员）。仅服主（原版 2 级 OP 以上）、服务器控制台或 BBS 等级 2 的玩家可用。
- `/bbsop <玩家> grant <域> <allow|deny>`：允许或禁止 1 级玩家的某个功能域；`/bbsop <玩家> grant reset` 恢复为不受限。域：morph、film、record、model_blocks、particles、model_editor、textures、audio、upload。

## 使用教程

### 安装
1. 安装 [Minecraft 1.20.1](https://www.minecraft.net/) 与 [Fabric Loader](https://fabricmc.net/use/)。
2. 把以下 jar 放入 `mods/` 文件夹：
   - Fabric API
   - BBS FS >= 2.6
   - `together-link-1.7.5-1.20.1.jar`
3. 服务端与所有客户端都需要安装相同版本的 BBS FS 与 Together Link。

### 开启多人协作
1. 启动服务端，玩家正常加入世界。
2. 任意玩家按 BBS 快捷键打开 BBS 仪表盘，新建或打开一个影片。
3. 其他玩家加入同一影片后，即可看到彼此的光标、选中颜色与实时修改。
4. 服务器管理员输入 `/bbstogether record @a` 可让所有人开始/停止录制。

### 配置
在游戏内打开 BBS 设置（Mods 列表 → Together Link → Config），可调整：

| 配置项 | 说明 |
|--------|------|
| CDN 地址 / 访问令牌 | 预留的 CDN 同步接口，留空则使用内置服务器直连 |
| 启用下载 | 开启后从服务器自动下载缺失资产 |
| 启用上传 | 开启后把本地资产上传到服务器 |
| 接收推送 | 开启后接收服务器推送的资产更新 |
| 关键帧默认颜色/形状/插值 | 新建关键帧的默认样式 |

配置文件位于 `config/bbs_together.json`。

### 资产目录
- 服务器权威资产目录：`<服务器目录>/config/bbs/assets/`
- 玩家资产会自动同步到此目录，服务器重启后不丢失。

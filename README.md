# Together Link

Together Link（模组 ID：`bbs_together`）是 [BBS FS](https://github.com) 的多人协作扩展，基于 Minecraft 1.20.1 Fabric。它在保留 BBS 原有编辑体验的前提下，提供多人实时协作、影片版本历史、服务端权限/资产锁、资产同步和服务器审计。

## 版本与前置

| 项目 | 要求 |
|---|---|
| 当前版本 | 2.0 |
| Minecraft | 1.20.1 |
| BBS FS | >= 2.6（推荐 2.7） |
| Fabric Loader | >= 0.15.6 |
| Fabric API | 必需 |
| Java | 17+（编译目标 17） |
| 许可 | MIT |

## 功能概览

### 实时协作

| 功能 | 说明 |
|---|---|
| 玩家颜色 | 每名玩家分配独立颜色，用于高亮其选中内容与光标 |
| 共享光标 | 其他玩家的光标位置实时显示 |
| 选中同步 | 表单、关键帧、回放片段的选中状态广播给在线玩家 |
| 表单锁定 | 同一回放表单被占用时显示锁定，避免并发修改 |
| 回放交换 | 支持交换玩家之间的回放顺序 |

### 影片、提交与分支

| 功能 | 说明 |
|---|---|
| 影片同步 | 影片选择、屏幕状态、关键帧/轨道修改实时推送 |
| 列表同步 | 新增、重命名、删除影片后所有客户端刷新 |
| 提交 | 每部影片保留提交图、快照和差异，默认最多 300 条 |
| 分支隔离 | 每名玩家可在独立分支工作，互不覆盖 |
| 退回/压缩 | 支持保留或删除后续提交的退回，以及压缩连续提交 |
| 提交详情 | 显示提交信息、作者、时间、剪辑/关键帧统计和差异 |
| 提交图 | 按影片分列、按时间排列，可见区域外连线自动裁剪 |
| 提交颜色 | 服务端保存并广播，所有玩家看到一致颜色 |

### 权限与资产锁

| 功能 | 说明 |
|---|---|
| 三级权限 | 0 只读 / 1 编辑 / 2 管理，按功能域细分 |
| 功能域 | 伪装、影片、录制、模型方块、粒子、模型编辑器、纹理、音频、上传 |
| 资产锁 | 模型、影片、模型方块可限制为白名单/黑名单 |
| 锁显示 | 无权限者看到闭合锁；创建者/管理员看到管理标记 |
| 锁保护 | 服务端复核上传、保存、右键和破坏；锁定方块不可被无权限玩家破坏或打开 |
| 文件锁 | 影片保存、改名、删除、撤销和文件夹操作统一经过 `FilmWriteGuard` |

### 资产同步

| 功能 | 说明 |
|---|---|
| 清单同步 | 服务器下发 assets 的 SHA-1、大小和 mtime |
| 自动下载/上传 | 客户端按清单差异自动同步缺失或变更文件 |
| 冲突仲裁 | 上传携带服务器 mtime 作为 CAS 令牌，避免覆盖他人修改 |
| 原子落盘 | 服务端本地校验 SHA-1，临时文件原子替换 |
| 分片隔离 | 多分片临时文件按玩家隔离，校验累计大小 |
| 大小上限 | 服务端和客户端共享 `asset_sync_max_mb` |
| CDN（可选） | 只读下载回退：优先 CDN，校验失败自动回退服务器 |
| 防复活 | 模型删除 tombstone 持久化，离线客户端不能重新传回 |
| 恢复 | `/bbstogether restore <模型>` 清除 tombstone 后允许重新上传 |

### 服务器审计

| 功能 | 说明 |
|---|---|
| 行为面板 | 记录编辑、下载、上传、删除请求等行为 |
| 去重合并 | 连续重复操作合并，未实际变更不产生记录 |
| 来源标记 | 客户端自报记录显示“客户端上报（未由服务端核实）” |
| 权限保护 | 非 OP 玩家匿名显示；日志删除仅 OP 或 BBS 等级 2 |
| 持久化 | `<存档>/bbs/behaviors/`，UTF-8 + 原子写 |
| 限流 | 行为上报与 manifest 查询按玩家限流 |

## 权限等级

| 等级 | 名称 | 能力 |
|---|---|---|
| 0 | 只读 | 浏览、下载；不可编辑、上传或管理 |
| 1 | 编辑 | 默认可编辑全部域；管理员可逐域限制 |
| 2 | 管理 | 编辑全部内容，管理玩家等级、功能域和资产锁 |

- 单人/LAN 存档的集成服务器会自动给开服者 2 级。
- 专用服不再自动把第一个进服玩家设为管理员；首次开服请由控制台执行 `/bbsop <玩家> 2`。
- 只有 BBS 等级 2 能始终绕过资产锁；锁创建者被降级后同样受锁限制。

## 服务器命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/bbstogether record <玩家>` | 切换目标玩家录制状态 | OP |
| `/bbstogether restore <模型>` | 清除模型删除 tombstone，允许重新上传 | OP 或 BBS 2 |
| `/bbstogether diag` | 输出资产同步/队列诊断 | OP |
| `/bbsop <玩家> [0-2]` | 查询或设置 BBS 权限等级 | OP/控制台/BBS 2 |
| `/bbsop <玩家> grant <域> <allow\|deny>` | 允许/禁止等级 1 的某个域 | OP/控制台/BBS 2 |
| `/bbsop <玩家> grant reset` | 恢复等级 1 为不受限 | OP/控制台/BBS 2 |

功能域：`morph`、`film`、`record`、`model_blocks`、`particles`、`model_editor`、`textures`、`audio`、`upload`。

## 安装与部署

| 步骤 | 操作 |
|---|---|
| 1 | 安装 Minecraft 1.20.1、Fabric Loader、Fabric API、BBS FS |
| 2 | 将 `together-link-2.0-1.20.1.jar` 放入客户端和服务端的 `mods/` |
| 3 | 启动服务器，使用控制台或 OP 执行 `/bbsop <玩家> 2` 初始化管理员 |
| 4 | 所有客户端连接同一服务器；服务端与客户端必须使用同一版本 |
| 5 | 进入 BBS 仪表盘即可开始协作 |

> 仅更新客户端不会生效：资产路径、权限、CAS、tombstone、合作录制锁等服务端校验都在服务端执行。

## 配置

配置文件：`config/bbs/settings/bbs_together.json`。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `cdn.url` / `cdn.token` | 空 | 可选只读 CDN 下载源；失败自动回退服务器 |
| `cdn.download` | 开 | 自动下载缺失资产 |
| `cdn.upload` | 开 | 自动上传本地变更 |
| `cdn.receive` | 开 | 接收服务器资产推送 |
| `cdn.progress_bar` | 开 | 显示左下角同步状态组件 |
| `cdn.progress_bar_always` | 关 | 空闲时显示小状态点 |
| `server.auto_sync` | 关 | 自动监听资产变更 |
| `server.asset_sync_max_mb` | 256 | 单文件大小上限，0 = 不限制 |
| `server.asset_upload_kbps` | 1024 | 上传限速，0 = 不限速 |
| `server.asset_egress_kbps` | 2048 | 服务端总出口限速，0 = 不限速 |
| `behaviors.behavior_log_limit` | 1000 | 行为日志条数上限 |
| `coop.coop_invite_seconds` | 60 | 合作录制邀请有效期（秒） |

## 兼容性

| 场景 | 行为 |
|---|---|
| BBS-only/原版服务器 | 不启用 Together 权限与同步，BBS 编辑保持可用 |
| 旧版 Together 服务器 | 通过首个权限同步包识别，保持兼容 |
| BBS-Cubed | 右键菜单在分类构建阶段过滤，保留 addon 追加项 |
| 影片分支 | 非默认分支保存写入分支存储，不覆盖主影片 |
| CDN | 只读下载回退；不支持 CDN 上传或 CDN manifest |
| 冲突令牌 | 基于服务器 mtime 的 CAS，不是严格单调 revision |
| 行为日志 | 有来源标记、类型/长度校验和限流；无服务端签名/审计链 |

## 更新日志

### v2.0

#### 安全

- Fix28 快照通道统一校验 FILM/RECORD 域、资产锁、删除 tombstone、合作录制锁和发送者身份。
- 资产上传、下载、manifest、客户端落盘和本地删除统一限制在 assets 根目录；拒绝绝对路径、盘符、UNC、`..` 和符号链接。
- Crusher 增加分片头校验、容量上限、过期清理和 gzip 解压上限；Together 通道按玩家使用独立 crusher。
- 模型、纹理、音频、粒子上传按路径映射到对应功能域，服务端复核。
- 新增 `s_hello/c_hello` 握手；BBS-only 服务器保持可编辑，旧 Together 服务器通过权限同步包兜底识别。
- Windows/macOS 模型锁 key 按大小写不敏感规范化。
- 专用服首个管理员改为控制台 `/bbsop <玩家> 2` 显式授予。

#### 同步与数据

- 上传改为服务端本地 SHA-1、临时文件原子替换、分片临时文件按玩家隔离并校验累计大小。
- 上传携带服务器 mtime CAS 令牌；他人已修改时拒绝覆盖并重新同步。
- 模型删除 tombstone 持久化；新增 `/bbstogether restore <模型>`。
- CDN 地址/令牌接入只读下载回退，SHA-1/大小校验失败自动回退服务器。
- 服务端下发 `asset_sync_max_mb` / `coop_invite_seconds`，客户端下载上限采用服务端值。
- 资产 HUD 改为左下角极简组件：活动时图标 + 2px 进度线 + 百分比，完成时对勾脉冲，空闲时状态点；绘制在所有栏/菜单之上但不拦截点击。
- 修复上传进度偶发无法收尾：新扫描清理旧任务，空任务列表自动收尾，活动/等待任务超时回收，状态转换可重新唤醒。
- 模型方块 NBT 超过 4 MB 时跳过 `BlockEntityUpdateS2CPacket`，避免超过原版 8 MB 上限导致断线；超大形态需重新加载区块。

#### 影片与界面

- 影片保存、改名、删除、撤销、文件夹操作统一经过 `FilmWriteGuard`。
- 文件夹改名/删除同步迁移/清理分支、提交、玩家选择、编辑状态、光标、表单锁和延迟保存任务。
- 非默认分支的 BBS manager 保存写入分支存储，不再覆盖主影片。
- 影片改名/删除改为成功后通知，避免 BBS 拒绝后服务端提前修改。
- 回放结构只保留专用 identity 协议。
- BBS-Cubed 右键菜单兼容；录制按钮单一权限 owner；`MorphRenderer` 只在影片界面隐藏。
- 锁菜单始终显示白名单/黑名单入口。

#### 运行与工程

- 服务端 manifest/请求/库存处理改为有界 I/O 线程池；上传分片改为单线程有序写入。
- 客户端 SHA-1 缓存、tombstone 数量加硬上限。
- 提交图增加可见边裁剪。
- 文件持久化改为 UTF-8 + 原子写。
- 行为日志增加来源标记、类型/长度校验和每玩家限流。
- 移除重复 l10n 注册；Loom 固定为 1.15.5。

#### 验证

- 2.0 构建通过（`BUILD SUCCESSFUL`）。
- 1.7.9 基线已完成客户端启动、单客户端服务端和双客户端连接冒烟；2.0 运行画面与双端交互待按验收清单复测。
- 完整双人 UI 验收清单见 [验收清单](docs/验收清单-TogetherLink-2.0.md)。

#### 已知限制

- CDN 仅支持只读下载回退。
- mtime CAS 不是严格单调 revision。
- 行为日志无服务端签名/审计链。
- `client-bbs-together-refmap.json` 为历史文件；生产 jar 启动已验证，未重新生成。
- 提交图已做可见边裁剪，全量 rebuild/布局仍有优化空间。
- 模型方块 NBT 超过 4 MB 时跳过其 BlockEntityUpdate 包，避免超过原版 8 MB 上限导致断线；客户端可能需要重新加载区块才能看到该方块的最新形态。
